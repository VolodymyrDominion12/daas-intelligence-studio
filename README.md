# DaaS Intelligence Studio (`daas-intelligence-studio`)

Локальна AI-платформа для інтелектуального парсингу, каскадного збагачення даних (Waterfall Data Enrichment), історичного моніторингу (Time-Series) та пакування датасетів для продажу бізнесам (Data-as-a-Service).

## Документація проекту

* 📄 **[01. Концепція та Архітектура Платформи](docs/01_CONCEPT_AND_ARCHITECTURE.md)** — огляд екосистеми AI-парсингу (Crawl4AI, Scrapling + Camoufox, Browser-Use, локальні моделі ReaderLM-v2), архітектура локального сховища (DuckDB + Parquet + SQLite + LanceDB) та дизайн пайплайну від текстової задачі в UI до готового комерційного датасету.
