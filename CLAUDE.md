# CLAUDE.md

Усі правила проєкту — в `AGENTS.md` (імпортується нижче). Головне: **Spec-Driven Development** —
жодної зміни поведінки без зміни спеки в `specs/`.

@AGENTS.md

## Специфічне для Claude Code

- Слеш-команди процесу (`.claude/commands/`):
  - `/sdd-specify <опис зміни>` — створити `specs/changes/NNN-slug/spec.md`
  - `/sdd-plan <NNN>` — `plan.md` з перевіркою конституції
  - `/sdd-tasks <NNN>` — `tasks.md`, тести першими
  - `/sdd-implement <NNN>` — виконати задачі, перевірити, синхронізувати спеки й архівувати
  - `/sdd-bugfix <опис бага>` — короткий шлях для бага (тест → фікс → посилання у спеці)
- Для широкого пошуку по коду використовуй субагента Explore; для плану великої зміни — Plan.
- Не позначай задачу виконаною, доки `make specs-check test lint` не зелені (або прямо скажи, що
  саме не вдалося запустити).
